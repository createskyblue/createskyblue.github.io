ESP32-S3 通用模板：WiFi 配网、OTA、文件管理开箱即用

基于 ESP-IDF v6.0.1 的 ESP32-S3 基础设施模板，提供 WiFi 配网、LittleFS、SD 卡、OTA 升级等开箱即用的功能，适合作为新项目的起点。

GitHub 仓库

功能一览

功能 说明
WiFi AP+STA 同时运行 AP 热点（ESP32S3-Template）和 STA 客户端
Web 配网 网页端输入 SSID/密码，配置持久化到 LittleFS，自动重连
Captive Portal DNS 劫持，手机连上 AP 后自动弹出配网页面
LittleFS 1 MB 内部闪存文件系统，存放网页和配置文件
SD 卡 SPI 模式，FAT 文件系统，支持热插拔（可选，失败不阻塞启动）
文件管理器 Web 界面浏览/上传/下载/删除/新建文件夹，支持内部 Flash 和 SD 卡双存储
OTA 升级 支持固件 + 文件系统远程升级，也支持网页直接上传刷写
SD 日志 所有 ESP_LOG 输出自动双写（串口 + SD 卡），定时滚动
SNTP 授时 STA 连接成功后自动同步北京时间
LED 指示 绿灯心跳（500ms 翻转），蓝灯 WiFi/数据活动指示
调试接口 /debug.json 查看堆内存、PSRAM、任务列表、运行时间

界面预览

架构

项目采用 平台 + 业务 分层架构：

  • main/web_platform.c — 基础设施胶水层，负责 WiFi / OTA / 配网 / 仪表盘编排
  • main/hello_web.c — 业务端点模板，从这里开始写自定义 HTTP handler
  • components/ — 可复用组件（wifi_manager、ota_manager、file_manager、led_task、sd_card、sd_logger）

新项目只需在 hello_web.c 中仿照模板添加 handler，基础设施已全部就绪。

快速开始

# 克隆模板
git clone https://github.com/createskyblue/esp32s3_idf_template.git my_project
cd my_project

# 编译烧录
idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor

首次上电：手机搜到热点 ESP32S3-Template（密码 template1234），连接后浏览器打开任意网址自动弹出配网页面。
