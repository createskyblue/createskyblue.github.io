点阵数码管与按键中央琥珀灯：一个 CSS 拟物粒子计数器面板

HTML/CSS 搭的尘埃粒子计数器面板。下面是两个组件的设计提示词，加上拨杆声的合成参数。demo 可以直接点。

实物参考

复刻自一台真实的 RION 尘埃粒子计数器（下图），整体配色与走线照它来。

点阵数码管组件

  • 结构：每个数字是一块 5×7 的小圆点矩阵，点为正圆。
  • 点亮态：绿色荧光圆点，中心偏白高光，带一圈绿色光晕（radial-gradient 渐变 + box-shadow 发光）。
  • 熄灭态：深绿色小圆点，隐约留下点阵网格，像没有通电的位。
  • 布局：10 位显示区，数字右对齐，左边未使用的位只显示暗点。
  • 底板：深色玻璃感，内凹，边缘有微弱反光。

拟物风格按键

  • 按钮：正方形凸起键帽、圆角，顶面高光、底边暗边，用 linear-gradient 模拟受光。
  • 指示灯：圆形琥珀灯装在按钮面板中央（灯在按钮上）。点亮为琥珀橙 #e89400 带光晕；熄灭为深色含琥珀调 #5f5340。

为什么熄灭态不落到纯黑：跟点亮的琥珀橙同属一套色相，整排灯看起来是同一批元件；暗态也能辨认这是琥珀灯珠，不会和滑槽阴影糊在一起。真实 LED 灯珠未点亮时，透光外壳往往带自身颜色，纯黑会失真。

  • 文字：档位标签印在按钮外面的滑槽下方，避免随按键移动。
  • 滑槽：凹进去的槽（inset box-shadow），四周留白统一，按钮不重叠。
  • 机箱：米白金属外壳、顶部饰边、品牌标识。
  • 交互：按下按钮本体下压（translateY 2px + 阴影收缩）。

按压与拨杆声的合成参数

用 Web Audio 实时合成，三个声源叠加：blip + noise + thump。

blip（咔哒主音）

  • 振荡器：square / triangle
  • 对数频率斜坡：f(t)=f0·(f1/f0)^(t/T)
  • 指数衰减增益：g(t)=v·e^(−t/τ)，τ=T/ln(v/0.0001)
  • 参数：老式键 f0=1450, f1=420, T=0.03, v=0.6；拨杆 f0=960, f1=500, T=0.04, v=0.42

noise（机械颗粒）

  • 白噪声线性衰减：n[i]=(2·rand−1)·(1−i/N)
  • 高通滤波：fc≈900–1600Hz
  • 参数：T≈0.016–0.032, v≈0.26–0.34

thump（低频共鸣）

  • 正弦频率斜坡：f(t)=F·(0.45)^(t/T)
  • 参数：F≈200Hz, T≈0.05, v≈0.3–0.34
